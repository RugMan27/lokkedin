# LokkedIn

## How to Install the Extension

1. Download the repository ZIP file from GitHub and extract it to your computer.
2. Open Google Chrome and go to the Extensions page (`chrome://extensions`).
3. Turn on **Developer mode** in the top right corner.
4. Click **Load unpacked** in the top left.
5. Open the extracted folder, go inside the `extention` folder, select the `dist` folder, and click **Select Folder**.
